# 📘 Text Preprocessing Project

## 📌 Overview
This project demonstrates the basic process of text preprocessing using Python and Pandas. The program reads raw text from a CSV file, cleans the text by removing punctuation and special characters, converts it to lowercase, and saves the cleaned text into a new CSV file.

## 🎯 Objectives
- Read text data from a CSV file
- Convert text to lowercase
- Remove punctuation and special characters
- Remove extra whitespace
- Save the cleaned text to a new CSV file

## 🛠️ Technologies Used
- Python
- Pandas
- Regular Expressions (re)
- Jupyter Notebook

## 🚀 How to Run
1. Install the required library:
   ```
   pip install pandas
   ```
2. Open the project in Jupyter Notebook.
3. Run the notebook or `preprocessing.py`.
4. The cleaned data will be saved as `clean.csv`.

## 📊 Features
- Reads raw text from `raw.csv`
- Cleans and preprocesses the text
- Displays original and cleaned text
- Saves the processed text into `clean.csv`

## 📁 Input
- `raw.csv` – Contains the original text.

## 📁 Output
- `clean.csv` – Contains the cleaned and preprocessed text.

## 📚 Learning Outcome
This project helped in understanding the fundamentals of text preprocessing, including text cleaning, normalization, and preparing textual data for Natural Language Processing (NLP) tasks.
